# 台股 1～5 日機率研究台

先取得真實行情，再進行分析。正式介面不生成、不提供、不回退到模擬價格。

- [開啟網頁](https://xtxgmxa.github.io/stock-analyzer-local/)
- [原始碼](https://github.com/xtxgmxa/stock-analyzer-local)

## v0.6 複製完整提示詞，交給外部 AI 深入分析

查詢完成後，在「帶去你自己的 AI，深入分析」按「複製完整 AI 分析提示詞」，貼到你常用的 AI。手機或其他電腦都不用啟動本機服務。外部 AI 需具備網路搜尋能力，才可實際查核新聞；本站只整理委託內容，不代為送出或宣稱已搜尋。

提示詞包含當次代號／名稱、行情來源與截止日、規則結論、完整技術指標定義與計算方式、最後 121 筆真實行情、可選的持有成本與損益，以及已載入模型的驗證摘要。模型尚未提供時保持 null；不能把技術分數當成機率。原始技術版的 ATR 實為收盤波動代理，統計帶也未做覆蓋率校正，提示詞均明確揭露。

外部 AI 受託核對近7／30天新聞與正式公告、日期與來源、ETF持股／淨值及個股財務、支持與反駁證據，並區分行情日當時可知資訊與事後更新。回報格式含白話結論、資料稽核、新聞證據表、1／3／5日情境、反證、失效條件及追蹤清單。不能上網時須揭露限制。

另提供「預覽／手動複製」和 UTF-8 文字檔下載；剪貼簿未授權時自動顯示可長按複製的完整內容。更換標的或成本後使用最新結果重新產生，行情讀取失敗時停用匯出，避免帶走上一次股票的結論。成本勾選可取消，帳號設定、憑證與個人資料庫不會進入提示詞。

## v0.5 手機輸入代號即可查詢

不用安裝、不用登入：開啟網站，輸入台股／ETF 代號，例如 2330、2317、0050、6488 或 00985A；停頓約一秒即自動查詢，也可按「查詢並分析」。
瀏覽器直接呼叫 FinMind TaiwanStockPrice 取得近 400 個日曆日的實際 OHLCV，完成資料檢查、圖表、技術觀察及內建摘要。查詢不經自己的電腦，不依賴維護者電腦開機。
資料為已完成日 K，不是盤中即時報價；來源可能延遲或受用量限制，失敗時停止分析，不產生模擬價格。

內建摘要是技術規則計算，不是假稱由 ChatGPT 或其他語言模型生成。
完整 LightGBM/XGBoost 機率模型仍只顯示已發布的研究；只有日期及每筆 OHLCV 與本次行情完全一致時才自動套用。
若資料版本不同，可另外選擇「查看已發布模型（歷史資料版本）」，畫面會切換至該模型的原資料來源與日期；不將舊機率冒充本次行情的預測。
重新訓練與個人 Codex/Cursor CLI 帳號仍屬進階選用功能，需要自己的本機服務。

完整研究使用 TWSE 官方資料，保留 v0.4 多訊號分析與每日預測對帳。畫面標示來源、資料日期與收盤價；本次直接讀取的 FinMind 行情若有不同，不會自動套用該機率。
公開網頁不需要安裝就能閱讀已發布的 2330、2454、1216 真實行情、機率研究、資料品質與內建摘要。2317 在 2025-07-30 缺少完整成交價，四年回測維持停止；手機仍可讀取最近一年通過基本檢查的行情作技術觀察，兩者明確區分。
資料是收盤後日 K，不是盤中即時報價。目前已在維護者的 Codex 設定每個工作日台北時間 18:30 更新、對帳與推送網頁。這是本機排程，電腦與 Codex 必須可執行；請以畫面日期確認是否更新成功。GitHub 雲端自動流程仍需 workflow 授權，目前未啟用。

未發布模型的股票可以直接查詢真實行情，但不補造經校正機率。超過 7 天、來源錯誤或資料驗證失敗時停止分析並顯示原因。

## 重新訓練完整模型與使用自己的 AI 帳號

Windows 安裝 Node.js 20+、Python 3.12 並加入 PATH，下載原始碼後：

1. 第一次執行 `setup.bat`，安裝專案專用環境。
2. 執行 `start.bat`，開啟 http://localhost:5177。
3. 本機服務從 TWSE 官方讀取上市股票日 K。上櫃可自行選 Yahoo 非官方 .TWO 來源或匯入真實 CSV。
4. 輸入代號，按「更新行情並分析」，確認來源與日期，再閱讀技術觀察或產生 AI 判讀。
5. 「執行訓練與回測」會抓取、驗證完整資料，再訓練 1～5 日模型；首次官方抓取約 1～3 分鐘。

Mac/Linux：`bash setup.command`，接著 `bash start.command`。已在 Windows 驗證；CI 包含 Ubuntu 檢查。

Codex CLI 需先 `codex login`，並可用 `codex login status` 確認登入。
Cursor adapter 預設 `cursor-agent login` / `cursor-agent status`，若版本使用 `agent`，可於 config.json 覆寫；Cursor 真實帳號尚未實測。
僅有桌面 App 登入不一定代表 CLI 已登入。各使用者使用自己的帳號、額度與資料庫，網站不接收 token。
AI 讀取目前已載入的真實行情、來源、日期、最近 60 個交易日 OHLCV 與分析快照；回覆顯示為中文卡片，原始 JSON 收在進階區。

在 GitHub Pages 使用本機帳號時，複製 config.example.json 為 config.json，將 allowedOrigins 設成 `https://xtxgmxa.github.io`，重新啟動本機服務。
瀏覽器可能要求本機網路存取權限；若政策阻擋，可直接使用 localhost 網頁。

## 研究核心

- 真實來源：TWSE 官方上市歷史日 K；明確選擇的 Yahoo 非官方 OHLCV；使用者確認來源的 CSV。
- 完整研究 CSV：`date,open,high,low,close,volume`，至少 650 個交易日，成交量單位為股。
- 嚴格檢查缺值、OHLC、重複、未來日期、未完成日 K 與疑似拆股大跳動。
- LightGBM + XGBoost baseline，各 1～5 日分開；技術、動能、波動、量能及流動性訊號。
- Expanding Walk-Forward：252 日起始訓練、100 日獨立校正、63 日測試，兩個邊界各留 5 日 purge。
- 上漲機率定義：第 h 日收盤是否高於次日開盤，為未扣成本的方向機率。
- 含手續費、稅、滑價、隔日開盤、ATR 停損、倉位上限及不重疊持倉的回測。
- SQLite 資料版本、每折稽核、逐筆 OOS、Brier/prior 比較、交易明細、資產曲線、歷史快照與 JSON 下載。
- 模型未優於基準時，最新訊號維持「觀察」，不宣稱有預測優勢。

完整方法與費稅假設見 ARCHITECTURE.md。研究資料庫與帳號設定不提供公開下載。
合成序列僅存在於單元測試的固定測試資料，不可由正式 CLI/API/介面用來分析。

## v0.4 如何判斷有沒有改善

同日期比較 16 個價量特徵與 30 個含大盤／法人特徵，使用相同 Walk-Forward、校正、成本及固定模型參數。
最後 63 筆 OOS 訊號另作比較報告；歷史資料曾用於舊版研究，不能宣稱是從未看過的新資料。真正未見的驗證由前瞻對帳逐日累積。
同時提供 20 日區塊重抽樣的 Brier 改善區間，避免只看小幅分數差異。跨股票／持有期比較尚未做多重假設校正，不應據單一改善宣稱穩定優勢。

「相近訊號」採歷史樣本外機率正負 10 個百分點，至少 30 筆才估算扣成本平均報酬。
歷史策略只使用訊號當日已實現的過去 OOS 結果作成本門檻，不用後來的結果回頭決定是否進場。

首次預測以股票／日期／期間／模型版本鎖定，重跑不覆寫；當日收盤後保存的結果才列入前瞻成績。
已到期結果以官方後續交易日開盤與期末收盤核對，保存結果資料版本，結算後不因後續來源修訂而覆寫。
回溯日期的重建明確排除；尚未到期不顯示命中率。對帳為固定持有期、包含觀察訊號，不是實際交易績效。

公開網站的三檔比較結果並未顯示全面、穩定提升，因此風控會保留「觀察」。新增功能不代表承諾更準。
